Overview

Probability and Statistics at FAST-NUCES Islamabad, Spring 2026. The repository has all thirty lectures with their practice question sheets, the two course textbooks, five assignments with my solutions, quiz papers and my solved quizzes, formula sheets, sessional solutions, notes for the final exam, an R script for data analysis and the final project statement.

Unit 1

Descriptive statistics

Types of data, charts, histograms, mean, median, variance, quartiles and box plots.

Unit 2

Probability

Sets, counting, laws of probability, conditional probability, trees and Bayes.

Unit 3

Random variables & distributions

Discrete, continuous and joint variables; binomial, Poisson, exponential, gamma, beta and normal.

Unit 4

Inference & regression

Limit theorems, estimation, confidence intervals, hypothesis tests, correlation and regression.

Get the Files

Clone everything with Git, or run the Lecture 28 R script.

Clone the repository

Command
git clone https://github.com/rohaan2802/Prob_and_Stat_Repo.git

Run the R script

Command
cd "Prob_and_Stat_Repo/Lecture #28"
Rscript "Lecture-28 Data Analysis Using R.R"

The R script works in base R. You can also open it in RStudio and run it line by line. The PDFs open directly on GitHub or in any PDF reader.
